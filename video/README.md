# 视频制作

最终路线采用“真实会话回放 + 真实验证命令 + 中文字幕”。视频没有配音和背景音乐，方便面试时现场讲解。

画面依次展示：项目与评测提交、runtime 边界、真实会话回放、generation diff、hidden grader、inspect、五次固定提交评测和仓库入口。回放段会一直显示“真实会话回放”，不会冒充实时模型调用。

## 生成方式

先确认 macOS 已允许当前应用录制屏幕，再运行：

```bash
bash video/capture.sh
bash video/render.sh
```

录制和成片保存在 `.nash/video/<run-id>/`，不会进入 Git。最终文件名为 `nash-demo-submission.mp4`。

成片参数为 1920×1080、30fps、H.264、AAC 静音轨。制作脚本使用 macOS 自带字体把 SRT 渲染成底部字幕轨，再由 FFmpeg 烧录到画面中；仓库同时保留可编辑的 SRT 和 ASS 文件。验收时检查时长不超过 2 分钟、文件不超过 200 MB、字幕可读、画面没有密钥或个人信息。

当前成片已通过完整解码和抽帧检查：时长 107.533 秒，大小 4,426,781 字节。回放段右上角持续显示“真实会话回放”，AAC 音轨保持静音，便于面试时现场讲解。
