# 题目约束与验收标准

这份文档把题目要求转换为开发时可检查的条件。原始 PDF 留在仓库外，不随源码发布。

## 必须自行实现的部分

Nash 需要与大语言模型交互，自主读写文件、执行命令，并完成真实编程任务。以下逻辑由本仓库实现：

- 对话历史与上下文管理
- 工具定义和本地执行
- 模型输出解析
- Agent 循环及终止条件
- 错误处理

可以使用模型厂商的 API 客户端库、OpenAI 兼容网关和模型原生 tool calling。项目不依赖 Agent 框架、Agent SDK，也不使用服务端托管的文件或代码执行工具。

## 提交要求

- 截止时间为 2026 年 9 月 2 日 24:00，北京时间。
- Git 仓库必须公开，并保留完整提交历史。截止时间后不再推送提交。
- API key 只从环境变量或未入库配置读取，也不能出现在文档和视频中。
- 最终压缩包以真实姓名命名，只包含 `README.txt` 和视频。
- `README.txt` 不超过 1000 个汉字，包含仓库地址、运行方式和特色功能。
- 视频不超过 2 分钟，使用 mp4 格式，文件不超过 200 MB。

## 工程验收

首个可提交版本至少满足这些条件：

- 能用一个 OpenAI 兼容模型完成跨文件的真实编程任务。
- 文件工具无法访问工作区之外的路径。
- 命令有工作目录、超时、输出上限和审批策略。
- 未知工具、错误参数、模型请求失败和命令失败都会变成可供模型处理的 observation。
- 达到轮数、工具调用数或重复失败上限时，Agent 能给出明确终止原因。
- 会话写入 JSONL，进程退出后仍能查看工具调用、结果和终止原因。
- 核心状态机与安全边界有不依赖真实模型和网络的测试。

## 演示验收

视频任务需要在干净副本中稳定复现，并满足下面的要求：

- 任务必须涉及理解已有代码，不能只生成一个新文件。
- Agent 至少读取代码、修改代码并运行验证命令。
- 终端输出能让观众看清当前动作和验证结果。
- 视频中展示一次轨迹查看，说明工具执行来自本地 runtime。
- 准备一份已验证的录屏副本和失败时的备用素材，但不伪造运行结果。
